# RF专项入口与验证范围

从准确RF芯片/模组、频段、天线类型/位置、功率、电源、外壳/电池/金属环境及制造叠层识别RF通道；NFC近场匹配与GHz天线/传输线分开处理。优先准确器件官方参考设计和天线指南，记录型号/版本/页码。

确认端口阻抗及传输模式，不默认所有RF端口50Ω。RF传输线按实际介质、铜厚、阻焊、参考面与过孔/连接器几何计算。匹配网络靠近指定端口且拓扑/接地按官方参考；元件Q、SRF、封装及布局寄生均进入评估。天线净空按实际天线要求，不统一挖空全板地。

回流参考连续，换层过孔与兼容参考地连接；围栏间距、天线走线宽度和禁布尺寸没有统一数值。匹配元件保留调试空间且不无意增加长支线。屏蔽罩与外壳金属对天线和匹配的影响单独审查。

计算按[mcp-tooling](mcp-tooling.md)调用rftools，结构图按需调用drawio；记录单位、输入、模型及误差/适用范围。解析计算、二维准静态求解、三维EM仿真各有边界，不相互冒充。VNA校准/去嵌、S参数、匹配、辐射/读卡距离和法规测试按实际设计阶段规划；未做保持待验证。

本模块提供RF工作路由与核验清单，尚未建立所有芯片/天线的经验证模板，不能据模块启用或工具安装声称RF设计已通过。
