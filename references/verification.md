# 核验与交付证据

历史报告仅证明对应修订。先记录当前工程、图页/PCB 身份、文件版本或校验值；修改前保留源文件与锁定对象基线。用户暂停或手动接管后停止写入；恢复工作先重新读取、比较，不重放旧坐标/布线补丁。

## 阶段核验

新板、电气/接口变更及样机验证按[HW-01～07](design-workflow.md)关联关键需求ID、计算与测试证据；仿真按风险选择，记录模型边界，样机未测项保留未验证。可交付已完成的设计阶段并列明待测项，不把EDA检查升级为实物/合规结论。

每次只复查修改影响的器件、网络和规则；阶段结束保留所需完整核验。导入/脚本返回成功后读回实际对象和网表，确认修改已应用。出现异常按实际错误修复或回退；不以重试次数代替结果。

PCB开始大规模布线与最终交付前执行[PCB-V07](pcb-stage-review.md)，按当前器件/电源脚清单检查覆盖与证据。另按 PCB-V08 分别运行项目规则门禁与当前 PCB 修订版 EDA DRC，二者都通过并分别保存执行时间、版本和报告路径；门禁通过不代表板级几何合格，DRC 零错误不代表规则门禁、装配、回流、阻抗或制造均已通过。每个适用规则记录通过、失败或有据的不适用；未检查、证据缺失或过期均不能宣布对应阶段完成。脚本检查记录完整性，不替代实际几何与电气审查。

## 原理图交付

原理图任务按 [SCH-01～27](schematic-style.md)及[检查清单](../assets/SCHEMATIC_REVIEW.md)逐页核验。纯排版比较修改前后网表；电气变化核对受影响网络、器件/封装/BOM及必要 PCB 同步。保留当前 EDA 原理图检查报告和 PDF 整页/局部视觉检查结果；不把 PCB 制造输出强加给纯原理图任务。

## PCB 最终检查

**PCB-V09：六类工程审查。** 电气连接由NETLIST/CONNECTIVITY/DRC记录；PI、SI、EMC风险、热分别用PI/SI/EMC/THERMAL记录，制造/装配用FAB记录，具体证据见[阶段审查](pcb-stage-review.md)。每类关联对象、当前修订、依据、方法/条件、验收值、结果/裕量、证据和未关闭项。pass只对应声明范围内实际完成的审查/计算等，不自动表示性能实测或认证通过；按风险选择仿真和样机测试，不一律要求全量SI/PI求解。确无适用对象时保留有据的不适用，不能将需要而未做的验证标为不适用。

RULE_GATE、PCB-P09/P10/P11在layout/final均为必填；最终还要求六类覆盖。RULE_GATE与DRC不能以not_applicable跳过。旧记录缺新项会被拒绝，应重审补证据，不批量填pass。规则维护只执行文档/工具检查，不虚构板级DRC。

| 项目 | 证据与完成条件 |
|---|---|
| 原理图—PCB | 同一修订逐引脚网络与器件比较；差异已解释，不擅自改电气功能 |
| 连通与铺铜 | 所有预期连接闭合，无遗漏飞线；重铺后检查孤岛、细颈及热连接 |
| PCB-V06 | 首次完整零错误 DRC→适用入口泪滴→重铺铜→完整 DRC；局部修复后重复至零错误。记录参数/范围/例外，导出含最终泪滴，丝印匹配当前脚序 |
| DRC | 当前原生工程实际执行的最终报告；非预期错误解决，例外逐项列出依据 |
| PCB-G06 | GND 过孔接入兼容地平面，无法布孔的位置与短线原因有记录 |
| PCB-G08 / PCB-L19 | 非GND连接后铺铜/缝合/DRC，再处理残余GND；用户已完成通道和敏感区与保护基线比较 |
| PCB-R07 | 独立检查同层中心线，非过孔 90° 转角为 0；采用 45°或相切圆弧；有ARC/CARC时检查真实弧长和全弧几何。只豁免真实过孔中心换层的投影方向变化，不为规避检查增孔 |
| PCB-R11 | 连续段线宽一致，电源/GND 的局部10 mil与恢复20 mil逐段有据；检查载流瓶颈 |
| PCB-L17 | MCU同层去耦、逐引脚原厂要求及低电感供地回路；大小顺序为有条件偏好，例外说明 |
| PCB-L20 | 逐个电源器件检查VIN/VOUT、电容归属、低电感回路和真实串联滤波拓扑；容量及启动/稳定性有准确器件依据，不把正常平面供电判为失效 |
| 差分 | 实际端点、两线铜长/长度差、线宽/净距、阻抗计算输入与结果、逐段真实参考回流 |
| PCB-L18 | 每颗晶振分别检查布局、拓扑、过孔、逐层无关线避让及铜皮/护地 |
| PCB-P09 | 物理层用途、EDA原生层类型、实际平面分区与Gerber一致；明确内电层时核对原生类型，转换后重验 |
| PCB-P10 | 内电层电源区域采用规则几何；必要避让拆为规则子区域并核对净距、最小铜宽、连通、回流与Gerber；无适用对象时记录依据 |
| 机械与丝印 | 板框/孔/锁定对象与基线一致；PCB-V04独立同网焊盘分离、以合规铜线/既定GND接入连接；PCB-V02 Arial/实际字形、字号笔画、开窗与孔口避让及走线投影例外有证据；LED与排针功能完整 |
| PCB-L21 | 外接排针靠边、Pin 1/逐脚标注/插拔空间正确；模块配合插座的间距与例外有据；新位置重新检查 |
| 制造输出 | 打开实际 Gerber/钻孔或约定生产格式，确认层序、板框、开槽、钻孔、阻焊与修订，按需核对 BOM/坐标/装配图 |

完整交付同时保留原生工程、规则配置、验证报告、制造输出和简短变更记录。离线候选或未导入路线不作为工程完成证据。

## 结论边界

装配审查覆盖同网焊盘相接/间距、器件本体及工具空间；去耦审查保留逐电源脚的实际供电与回地路径，分别记录几何通过和待实测项。电气DRC零错误不能替代这两项。

文档门禁证明规则入口存在；DRC 证明其覆盖的规则；阻抗计算证明指定模型下的计算结果。它们都不能代替 SI/PI、载流/温升、起振、EMC 或实测。无法获取可靠网表、铜皮或工具时，标记无法验证的对象和范围。

状态使用“通过/失败/未检查/不适用”，后两者写理由。报告包含修订、时间、工具版本、证据文件和未关闭问题。Token/费用仅从可用用量记录统计；缺少记录就说明不能准确计量，不承诺固定节省比例。
